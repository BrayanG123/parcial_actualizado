# Wiki del proyecto

La base de conocimiento de FashionStore está en `D:/BOVEDAS PROYECTOS/1er_parcial_boveda`.

- Antes de modificar una funcionalidad, consultar `00_INDEX.md` y las notas relacionadas de la bóveda.
- Al implementar o refactorizar, actualizar en la misma tarea las notas afectadas: comportamiento, contratos, reglas, límites, fuentes y fecha de revisión.
- Registrar decisiones arquitectónicas relevantes en `decisiones/` usando `plantillas/Plantilla_ADR.md`; no crear un ADR por cada corrección menor.
- Mantener los enlaces Wikilink y actualizar `00_INDEX.md` cuando aparezca un módulo o nota importante.
- El código y las migraciones actuales prevalecen sobre documentación histórica. Distinguir implementación, verificación realizada y pendientes; no inventar resultados ni motivaciones históricas.
- No copiar secretos, tokens, datos personales reales ni contenido de `.env` a la wiki. Usar nombres de variables y ejemplos ficticios.
- Leer `Mantenimiento_Wiki.md` para el flujo completo. Si la bóveda no está disponible, informar qué actualización documental quedó pendiente.

Estas instrucciones complementan las instrucciones específicas de cada subdirectorio, como `mobile/AGENTS.md`.
